### 终极外挂方案：控制台注入抓取

请按照以下步骤，把这段“榨汁机”代码放进飞书文档里跑起来：

**第一步：** 停留在你想抓取的飞书文档页面，按 `F12` 打开开发者工具，进入 **Console（控制台）**。

**第二步：** 复制下面这段 JavaScript 代码，粘贴到控制台的最下方，然后按 `Enter` 回车运行：

```javascript
// 🥷 飞书文档专属：虚拟列表 DOM 榨汁机 🥷
window.capturedText = new Set();

console.log("%c🟢 开始抓取！请现在开始匀速往下滚动文档...", "color: #10B981; font-size: 16px; font-weight: bold;");

// 每 500 毫秒撒一次网，捕获当前视口内渲染的所有文字
window.captureInterval = setInterval(() => {
    // 飞书的文本块通常挂载在这些层级深处的 span 或 div 里
    // 这里的选择器尽可能泛化，抓住所有长文本
    let blocks = document.querySelectorAll('.docx-block, div[data-record-id], span[data-string]');
    
    // 如果上面没抓到，直接暴力抓取所有带文字的普通节点
    if (blocks.length === 0) {
        blocks = document.querySelectorAll('p, .text-block');
    }

    blocks.forEach(block => {
        let text = block.innerText || block.textContent;
        if (text) {
            text = text.trim();
            // 过滤掉太短的无意义字符或侧边栏 UI 文本
            if (text.length > 3) {
                window.capturedText.add(text);
            }
        }
    });
}, 500);

// 定义一个停止并下载的机关
window.stopAndExport = function() {
    clearInterval(window.captureInterval);
    console.log("%c🛑 抓取停止！正在为您打包生成文件...", "color: #EF4444; font-size: 16px; font-weight: bold;");
    
    let result = Array.from(window.capturedText).join('\n\n');
    
    // 生成 txt 文件并触发浏览器自动下载
    let blob = new Blob([result], { type: 'text/plain;charset=utf-8' });
    let a = document.createElement('a');
    a.href = URL.createObjectURL(blob);
    a.download = '飞书题库提取.txt';
    a.style.display = 'none';
    document.body.appendChild(a);
    a.click();
    document.body.removeChild(a);
    
    console.log("✅ 下载已触发！请检查浏览器的下载记录。");
};

console.log("%c💡 提示：当你滚动到底部后，请在控制台输入 stopAndExport() 并回车来下载文件。", "color: #3B82F6; font-size: 14px;");
```

**第三步：** 回车运行后，控制台会弹出绿色的字：**“🟢 开始抓取！”**。
这时候，你什么都不用管，只需用鼠标滚轮或者触控板，**以能看清文字的匀速，一路往下划**。因为它是虚拟列表，所以你滑到哪里，网页渲染到哪里，我的脚本就会在那一瞬间把 DOM 里的文字扣下来存进内存（Set 结构会自动帮你去重，不用担心重复抓取）。

**第四步：** 当你滑到 323 题的最底部时。回到 Console 控制台，输入下面这个命令并回车：
```javascript
stopAndExport()
```

这时候，浏览器会瞬间弹出一个下载框，一份名为 `飞书题库提取.txt` 的纯文本文件就落入你的本地硬盘了。

> **工程化善后说明：** > 这个粗暴提取法拿到的文本可能会稍微丢失一点排版（比如标题加粗没了），可能会混进去几句网页边栏的“目录”、“点赞”字眼。但这不重要！拿到原始语料后，你扔进 VS Code，用正则表达式或者顺手让大模型帮你重新清洗一下格式，它就会变成最纯粹的 Markdown 矿石。
